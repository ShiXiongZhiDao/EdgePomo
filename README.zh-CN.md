# EdgePomo

[English](./README.md) · **简体中文**

<p align="center"><img src="assets/app-icon.svg" width="80" alt="EdgePomo 图标"></p>

> 一个常驻在屏幕边缘的番茄钟。——几 MB 的小东西，无需注册、无需登录、不额外装任何运行时，下载安装即用。

---

## 界面速览

一条贴在屏幕边缘的细长条。从上往下依次是：一枚**番茄徽章**（写着当前任务还差几个番茄钟）、**当前相位**（工作 / 休息 / 长休）、大号**剩余时间**，时间下面就是**当前任务的名字**，再往下是四个按钮——**播放**、**跳过**、**重置**、**设置**。侧栏本身就是进度：一根玻璃管里的水柱，水面到哪就是时间到哪。

<img src="assets/imgs/dock-tomato.jpg" width="760" alt="侧栏（甜心番茄皮肤）：贴在屏幕右边缘，像任务栏一样独占一条边">

*真机上的侧栏（甜心番茄皮肤）：贴在屏幕右边缘、像任务栏一样**独占**这条边——桌面上的内容一点没被挡住。*

开启**鼠标离开时精简**后，指针不在侧栏上时文字、数字与按钮会收起，整条只剩纯净的进度；鼠标移回来就再现。

界面就这些。齿轮后面那个窗口有五页——**首页**（任务）、**报表**、**番茄钟**、**侧栏**、**设置**，用来改时长、贴边、提示音、皮肤、主题和语言——打开一次，改完关掉，之后基本不用再管它。

<img src="assets/imgs/page-tasks.jpg" width="760" alt="首页（今天）：一排四个指标 + 任务列表，二级菜单右端就是搜索框">

*首页（今天）：一排四个指标（待完成 / 预计时间 / 已完成 / 已专注），下面就是任务；二级菜单右端那个框是搜索。*

## 为什么需要它

Windows 只给你一个时钟，而一堆网页番茄钟给你一个随时会丢的标签页。真正在干活的时候，它们都不太称手：

| 你想要什么 | 一般的计时器 | EdgePomo |
|---|---|---|
| 随时看到还剩多久 | 得先把窗口或标签页翻出来 | 它本来就在屏幕边缘，**整条就是进度条** |
| 别挡住我正在做的事 | 悬浮窗盖在你的窗口上 | 像任务栏一样独占一条边，别的窗口最大化时自动避开 |
| 到点一定要知道 | 一条弹窗，还可能被专注助手吞掉 | 三条互不相干的通道：侧栏脉动 + 提示音 + 系统通知 |
| 知道今天做了多少 | 自己数 | 自动统计今日完成轮次，每天零点重置 |
| 换台电脑接着用 | 数据留在那台机器上，得手动拷 | 打开**云同步**（挂在**你自己的 WebDAV** 上），改动加密后自己过去 |
| 看视频 / 打游戏 / 做演示 | 悬浮件一直碍事 | 检测到全屏就自动让位，退出全屏自己回来 |

## 功能一览

### 侧栏

- **整条就是进度条**。相位沿侧栏回缩，像一根玻璃管里的水柱，水面在哪就是时间到哪；点一下侧栏还会荡开一圈涟漪，让这一下操作有反馈。不需要另开一个窗口盯着。
- **四块皮肤**。**甜心番茄**（默认，柔柔的写真背景，顶上缠着藤条）、**简约清新**（冷蓝灰墨，干净利落）、**暗色极简**（固定暗底，除了数字没别的）、**暖心手绘**（奶油纸 + 手绘插画）。四块共用同一套版式——徽章 / 相位 / 倒计时 / 任务 / 按钮，切换立刻显在真侧栏上。贴下边又选最薄那一档时，Windows 留下的空间不够，侧栏会退成只剩时间与进度，而不是把按钮裁掉一半。
- **自己搭一套主题**。挑一块皮肤当模板，然后**只选一个主题色**：进度条、按钮、相位点、徽章、卡片整套跟着换，而深浅结构仍听模板的（浅色模板派生出来还是浅色）。嫌不够细？**「高级设置」**把部件逐个拆开——背景 / 水柱 / 文字 / 卡纸 / 徽章 / 按钮，每样还各带一只透明度滑块，改一下侧栏立刻变。主题还可以拿**你自己的一张图**当侧栏背景，徽章里那枚番茄也能换成你的图标（保留原色，或统一染成主题色）。正式版留一个自定义主题的位置，这是刻意的。
- **底色与质感**。侧栏**背景颜色**、**透明度**（不透明 / 轻透 / 半透 / 微透）与一层低调的**背景纹理**（平滑 / 柔光 / 磨砂）集中在同一处；主题里没设的项，就用这几条全局值。
- **相位一眼可见**。工作 / 休息 / 长休各有自己的颜色，暂停时整条变淡；一段结束时开始脉动，直到你确认。
- **徽章上写着还剩多少**。侧栏顶端那枚番茄带着一个数字：当前任务还差几个番茄钟——不用自己数；没给任务做估算时，它就不显示数字。
- **四个按钮**：播放 / 暂停（时间到时变成**确认**）、**跳过**当前相位、**重置**本相位、以及打开**设置**的齿轮。
- **两个快捷操作**：直接点侧栏空白处（按钮以外）即可开始 / 暂停 / 确认，按 **`Esc`** 效果相同。
- **鼠标离开时精简**。默认关闭。打开后，指针不在侧栏上时整条只剩进度那一条，鼠标移回来文字、数字与按钮才再现。
- **贴哪条边、多厚随你**。左 / 上 / 右 / 下，72 / 88 / 104 三档，改完立即与系统重新协商，不用重启。

<img src="assets/imgs/skins.jpg" width="574" alt="另外三块皮肤：简约清新 / 暗色极简 / 暖心手绘">

*另外三块皮肤（左 → 右）：**简约清新** · **暗色极简** · **暖心手绘**。默认那块是**甜心番茄**——本页最上面那张侧栏就是它。*

### 到点怎么提醒你

三条互不相干的通道——因为只靠 Windows 通知并不牢靠：

1. **侧栏脉动**：纯视觉，永远有效。
2. **提示音**（默认开启）：按三个时点分开设置——*专注结束*、*短休结束*、*长休结束*，每一处各挑自己的音色（叮 / 咚 / 嗡 / 啦），也可以各用自己的音频文件；每一行都有试听按钮，不用等下一轮才知道选成了什么。
3. **系统通知**：人在别处时靠它。

### 全屏自动让位

打游戏、看全屏视频、做演示时，EdgePomo 会检测到并让开，绝不挡你的内容；退出全屏后自己回来。

### 第一次打开有一段一分钟的引导

首启时会有一个聚光引导，把该认识的东西在它本来的位置圈出来：导航在这条悬浮胶囊里、先加一件事、这排段控切要看哪些任务、双击任务就开始专注、**你屏幕那条边就是进度条**、以及开机自启为什么值得开着。它只指路、不要求你当场操作，任何一步都能**跳过**或按 `Esc` 出去，出去后回到你原来那一页。想再看一次：**设置 → 支持与帮助 → 重新观看新手引导**。

### 任务

- **给计时器绑一个当前任务**。任务名显示在侧栏倒计时正下方，顶端那枚番茄徽章数着它还差几个番茄钟；任务列表里则写成 `2/5`。
- **在任务列表里直接开始专注**。双击一条任务——或按它那颗播放键——它既成为当前任务，倒计时也**立刻跑起来**。那颗按钮此后跟侧栏同步：正在跑时它是暂停，两边任意一边按暂停，另一边跟着变。
- **八个 tab 分了组，不用挨个点**。**时间**（今天 · 明天 · 本周）与**状态**（收件箱 · 高优先级 · 过期 · 已完成），再加一轴**标签**。每项都带实时计数，不点进去就知道事在哪；打开应用看到的是**今天**，每个视图自己按截止日与优先级归位。这一排是标准标签列表——`←` / `→`、`Home` / `End`、读屏标题都有。
- **那一行右端是搜索框**。输入即筛，切视图不丢关键词。搜的是**标题和备注**两处，大小写不敏感、也不用输全——「写」能搜到「写 ADR」，「adr」能搜到「整理 adr 索引」，**最像的那条排最前**（完全相等 › 前缀 › 词首 › 中间），命中的字在标题上高亮。活动任务与「已完成」用**同一套匹配口径**，不会同一个词在「今天」搜得到、在「已完成」搜不到。搜索时快速添加那一行会收起（这时要的是结果，不是输入框），搜不到时给的是「没有匹配 X 的任务」，而不是「今天还没有安排」。
- **每个 tab 顶部有一排汇总**。待完成数、预计时间；有对应时间窗的视图还给出完成任务数与已专注时间。
- **标签用来给任务分组、给报表上色**。「标签」这一屏一件事：既看分布（每个标签多少条任务），也就地新建 / 改名 / 换色 / 删除。点任意一个标签（含「无标签」）就地展开它的任务，勾选、编辑、删除都不用离开这一屏。
- **编辑是一侧抽屉，不再把列表撑长**。点铅笔在任务列表右侧拉开抽屉（不盖标题栏、也不盖导航）：备注、截止日、计划日期与时间、优先级、标签、1–5 的番茄估算、**这个任务自己的番茄时长**（1–180 分钟，长任务可以按 45 分钟倒数，小任务按 10 分钟），还有**重复**——每天 / 每工作日 / 每周 / 每月。`Esc`、点遮罩、右上角叉都能收起。
- **快速添加仍然很快**。今天 / 明天 / 本周 / 收件箱各有一行输入口，标题、估算、标签一行搞定。从**本周**加的任务默认截止本周日——是「本周内某天」，不是「今天」。
- **手动完成**：勾一下圆圈，任务冻结并从计时器解绑——而且只有**完整走到零**的工作段才计数，跳过或中途停掉都不算。空列表也不只是一行小字，会告诉你下一步该去哪。
- **估算跑完，它自己进「已完成」**。把估算的番茄全部跑完的那一刻，等同于你点了那个圆圈：进「已完成」、计入今日完成数，并从侧栏的「当前任务」上解绑。三个例外：**重复任务**不参与（“每天”的任务本来就要每天打卡）、**估算填 0**（未估算）的不参与——这也成了单条任务的开关、跳过或中途停止不算一个番茄也就不会触发。⚠️ 新任务估算**预填 1**，所以多数任务是「跑完一个番茄就归档」，想多跑几轮就把估算调大；而归档会顺带清空当前任务，**下一个番茄需要你重新选一次要专注哪条**。
- **忘了先选任务也能开跑**。在工作相位直接按开始、而手上没有绑定任何任务时，会**自动建一条「未定义任务」**（估算 1）绑上去，跑完照常计数、照常归档——不会出现“跑完了却不知道算给谁”。
- **「已完成」的行上有专注时段**。行右端竖排两行 `HH:mm`，是这条任务**所有专注段**的跨度（最早一段的开始 → 最晚一段的结束），中间一根竖杠连着；鼠标停上去能看到完整那句。它只长在已完成的行上。

### 统计

打开 **「报表」** 看专注时间都花到哪了。

<img src="assets/imgs/page-stats.jpg" width="760" alt="报表页：周期切换 + 概览卡 + 这一周每天的专注时长">

*报表（本周）：上面是概览卡（专注时长 / 完成番茄 / 任务 · 完成 / 专注次数），下面这一周的每天专注时长。*

- **四档周期，一键切换**。今天 / 本周 / 本月 / 本年（自然年）。用 **‹ ›** 在时间轴上前后翻，随时可以一键跳回今天。
- **摘要卡片**给出所选周期的：专注时长、完成番茄数、任务数（另写其中完成了几个）、专注段数；外加一条**日均**，以及一段正在进行时的提醒。
- **拆解**：按**标签**（彩色，无标签也算进分母）与按**任务**（条形图，还给出完成 / 估算）两个维度，外加一条**趋势图**（月图按天、年图按 365 天）。
- **指标切换**：专注时长或番茄数都可以驱动这两个拆解图。
- **专注历史**列出这一周期内每一段专注——完整走完 / 主动停掉 / 被打断 / 意外结束——日子差的时候能说出差在哪。
- 历史只读——之后删任务不会改写过去，因为报表在记录时就把任务名快照了下来。

### 设置

左侧那条悬浮胶囊有五个页面：**首页**（任务）、**报表**（统计）、**番茄钟**、**侧栏**，以及底部的**设置**。

**番茄钟** —— 专注 / 短休 / 长休时长（默认 25 / 5 / 15 分钟）、每几轮来一次长休（4 轮）、自动开始下一段，以及整块提示音。四个数字都能直接键入，不必拿 ± 一颗颗按。

<img src="assets/imgs/page-pomodoro.jpg" width="760" alt="番茄钟页：时长与节奏 + 提示音">

*番茄钟页：时长与节奏（数字可直接键入），下面是提示音——总开关 + 三个时点各配音色或自己的文件。*

**侧栏** —— 贴哪条边、厚度（被任务栏截时写明这条边实得多少）、侧栏显不显示、鼠标离开时精简，以及进**「侧栏外观」**的入口：四块皮肤、自己的主题、与全局的背景色 / 透明度 / 纹理。

**设置** —— 外观（浅色 / 深色 / 跟随系统，主题配色：薄荷绿或番茄红，界面语言：English 或 简体中文）、系统（开机自启动、关闭时最小化到托盘）、数据（数据存在哪、搬走它）、**云同步**（多台设备之间同步，见下一节）、支持与帮助（重新观看新手引导、匿名使用统计、链接），以及**检查更新**。

## 常驻能力

- **系统托盘**：左键单击托盘图标直接唤回设置窗口；右键弹出 **显示主窗口 · 显示侧栏 · 开始 / 暂停 · 退出** 菜单；悬停会显示剩余时间。
- **开机自启动**：在你想起它之前就已经在那儿了。
- **单实例**：再次启动不会开出第二条——只是把已经在跑的那个叫到前台。
- 关掉设置窗口只是隐藏，侧栏照常计时。

## 数据可以放在你自己挑的文件夹

- 所有东西都住在一个应用数据文件夹里：任务、专注记录、标签、主题、提示音、背景图、偏好设置。
- **设置 → 数据 → 更改位置…** 把整个目录搬去你选的地方——备份盘、移动盘、任意位置。它是**复制**而不是移动，旧目录原封不动，**改回默认位置**一直在；新位置下次启动生效，而旧目录里比它新的文件会在启动时自动补齐。**在文件夹中显示**随时打开当前目录看个究竟。
- 备份从此不是一个动作，而是这个文件夹本身的属性：让备份任务盯着它、定期拷到别的盘，或者整包交给另一台机器。（实时同步盘是例外，见下面的常见问题。）

## 两台电脑，同一份任务

**设置 → 云同步**（默认关闭）。这里**没有 EdgePomo 的云**——同步盘是**你自己的**（本机的一个网盘同步文件夹，或你自己的 WebDAV），也不需要注册任何账号。打开它、点「配置…」，把**同步目录**指到一个网盘同步文件夹（OneDrive / iCloud / Dropbox / 坚果云桌面端），或者直接填 **WebDAV** 地址（坚果云、Nextcloud、ownCloud、群晖）——填一次账号（坚果云的账号是**注册邮箱**）与应用密码，解锁后就自己工作。改动大约**一分钟内**出现在你的其它设备上，不用点任何按钮。

<img src="assets/imgs/cloud-sync.jpg" width="760" alt="设置 → 云同步：页面上只留一行入口，配置全在右侧抽屉里">

*设置 → 云同步：页面上只留一行入口与状态（出问题的提示也留在页面上），配置在右侧抽屉里——载体、目录、账号、应用密码、同步口令。*

- **同步的是加密的改动流水，不是数据库文件**。AES-256-GCM 加密，密钥由你设的**同步口令**派生；云端（与网盘服务商）拿到的是一堆读不懂的文件，口令本身不上传。
- **没有「冲突弹窗」这回事**。每台设备只写自己的文件、也只删自己的文件；同一条记录被两台设备改过，就按**删除 / 完成 / 内容**三条时间轴各取最新、静默合并，被盖掉的那一版留在本机 30 天。
- **换台新设备 = 回放一遍**。在新机器上填同一个目录与同一个口令，全量就回来了，不必手工拷贝；那台机器随后也自动成为一份冗余副本。
- **口令默认只保存在内存里**。重启 EdgePomo 后要重新输——这是刻意的（否则「拿到数据目录」就等于「拿到全部明文」）。嫌麻烦就打开**「记住口令」**：它用 Windows 的凭据加密（DPAPI）把应用密码与同步口令存在本机，**只有这台机器上的这个 Windows 账户能解开**，重启后自动解锁、两个框自己填上（`***` 掩码）。⚠️ 反过来也成立：换电脑、重装系统要重输一次，而**已经能登录你这个 Windows 账户的人可以解开它**。勾上之后要**下一次成功解锁**才真正写盘——面板上那行小字会如实告诉你现在是「本机已保存」还是「还没写到本机」。
- 🔴 **忘了解锁口令 = 那批数据永久解不开**（密钥由口令派生，没有后门）。本机数据不受影响、照常用。所以面板上有一颗**「导出完整备份」**——它导出的是一份明文库，请自己收好。
- ⚠️ **同步目录要放在网盘里，数据目录不要**。两句看着矛盾，其实是两份不同的东西：数据目录里是数据库文件，会被网盘的占位文件与实时同步写坏；同步目录里放的是**只增不改**的加密流水，恰恰要靠网盘替你搬。同步目录请建在一个**已有的文件夹**里面——中间缺的层级会自动创建，但直接写在网盘根下的目录以后删不掉（只能去网页端清理）。
- 面板上能看到**状态、上次成功同步、上次错误**，以及操作日志的体积。同步悄悄坏掉几个月是这个产品最怕的事之一，所以它不会安静地失败。

## 更新、数据与卸载

**更新**：到 **设置 → 检查更新**。发现新版本会弹窗提示，可选立即安装、稍后处理，或忽略这个版本（会记住，不再弹它）。

**更新会丢数据吗？** 不会。更新只覆盖程序文件，你的时长设置、偏好、任务与历史全部原样保留。

**我的数据存在哪？** 一个用户目录下的文件夹，除非你在 **设置 → 数据** 里把它搬走过——那里会写明路径，也能直接打开。拷走那个文件夹就是全部备份。

**卸载**：在「设置 → 应用 → 安装的应用」（Windows 10 为「应用和功能」）里找到 **EdgePomo** 卸载即可。卸载器**不会删除**数据目录；想彻底清掉记录（比如把电脑送人），卸载后再删掉 `%APPDATA%\com.shixiong.edgepomo`（或你改过的那个目录）。

## 隐私说明

**默认全部留在本机。**任务标题与备注、标签名与主题名、专注历史、时长、偏好、音效与图片都只写进本地文件：不需要账号、不需要登录，EdgePomo **自己没有服务器**，也没有可供你上传的云端存储。

**多端同步靠你自己的 WebDAV**（默认关闭）。在**设置 → 云同步**里填**你自己的** WebDAV 地址（坚果云、Nextcloud、ownCloud、群晖），或者指一个本机的网盘同步文件夹，应用就把一份**加密的改动流水**写到**你自己的盘**上，让多台设备之间保持一致。密钥由你设的同步口令派生，网盘服务商和我们一样读不出明文。代价写在明处：**谁拿到同步口令谁就能解开它**，而**口令丢了那批数据就永久解不开**。

除了同步本身要联网，其余的一切——侧栏、闹钟、报表、文件——拔了网线照常用。

## 常见问题

**Q：侧栏不见了。**
右键托盘图标 → **显示侧栏**。如果还是不出来，看看是不是有程序正在全屏——那是它隐藏的另一个原因。

**Q：侧栏只剩一条颜色，数字都不见了。**
那是**鼠标离开时精简**：指针不在侧栏上时内容收起，移回来就再现。想一直看到数字就到「侧栏」页把它关掉。

**Q：侧栏比我设的厚度薄。**
贴下边时任务栏要分同一块空间，Windows 分给 EdgePomo 的就少了。「侧栏」页会写明这条边实得多少像素；想要完整厚度就换一条边。

**Q：没听到提示音。**
确认「到点响提示音」开着、系统音量没静音，并在「番茄钟」页用试听验证——三个时点是分开配的，专注结束时响的不一定是你给休息结束选的那个。**提示音才是主提醒通道**——别只依赖弹窗，专注助手会把它静音。

**Q：通知没弹出来。**
多半是 Windows 那边拦住了：检查**设置 → 系统 → 通知**，并关掉专注助手 / 免打扰。此时侧栏依然会脉动并响铃。

**Q：跳过或停掉的那一轮算数吗？**
不算。只有**完整走到零**的工作段才计数。今日完成数每天零点重新计。

**Q：为什么再启动也开不出第二条？**
这是有意的。两条侧栏会各自占工作区、各跑各的计时、各响各的铃。再次启动只会把已运行的实例叫到前台。

**Q：换电脑 / 重装系统，历史能带走吗？**
能，两条路。把整个数据目录拷到新机器的同一路径即可（**设置 → 数据** 会写明它是哪个文件夹）；或者在新机器上打开**设置 → 云同步**、填同一个同步目录与同一个口令，全量会自己回放回来——⚠️ 但「记住口令」存的那份凭据跟着 Windows 账户走，换机后要重输一次。

**Q：能不能直接把数据放 OneDrive / iCloud，两台机器自动一致？**
不建议直接放那个目录：实时同步工具会拿占位文件替掉真文件，也会在 EdgePomo 写到一半时插手，可能把写入弄坏。数据还是留在本地，靠定期拷走它来备份。**想让两台机器自动一致，请用「设置 → 云同步」**——它写进网盘的是只增不改的加密流水，正是为这个场景做的。

**Q：两台电脑能自动同步吗？**
能，**设置 → 云同步**（默认关闭）：把同步目录指到网盘同步文件夹，或填你自己的 WebDAV 地址（坚果云等），再设一个同步口令。改动大约一分钟内自己过去。开启**「记住口令」**之后重启不用再输（那份凭据只有这台机器上的这个 Windows 账户能解开）。

**Q：忘了同步口令怎么办？**
那批**云端数据永久解不开**——密钥由口令派生，我们也没有后门。本机数据不受影响，照常用。想给自己留条退路，就用云同步面板上的**「导出完整备份」**导出一份明文库存好。

**Q：同步目录我随便填一个行不行？**
两条规矩：① 要建在一个**已有的文件夹**里面（中间层级会自动创建，但直接写在网盘根下的目录以后删不掉，只能去网页端清理）；② 它和**数据目录是两回事**——数据目录别放网盘，同步目录才应该放网盘。

**Q：引导关太快没看清，能重看吗？**
能。**设置 → 支持与帮助 → 重新观看新手引导**。

**Q：杀毒软件报毒。**
未签名的小工具容易被个别杀软误报。安装包来自本仓库的 Releases 页面，可自行核对。
